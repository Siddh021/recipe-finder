# RecipeFinder

A modern and intuitive recipe discovery application built with **Angular** designed to help users easily browse, search and explore a wide range of delicious recipes. The application provides a clean user interface with detailed recipe pages and smooth navigation across devices.

---

## 🚀 Project Description

**RecipeFinder** allows users to:

* Browse a complete collection of recipes with rich visuals.
* Use search and filter options to quickly find desired dishes.
* View full recipe details including cook time, servings, ingredients and instructions.
* Navigate effortlessly across Home, Recipes, About and FAQ sections.
* Enjoy a fully responsive design optimized for desktops, tablets and mobile devices.

The project is structured using standard Angular CLI conventions and follows scalable component-based architecture.

---

## 🧱 Framework Used

This project is built using:

* **Angular** – Frontend framework
* **TypeScript** – Primary development language
* **HTML5 & SCSS** – UI markup and styling

## 🛠️ Setup Instructions

### **Prerequisites**

* Node.js (v18 or later recommended)
* npm (comes with Node)
* Angular CLI (21.0.0)


npm install -g @angular/cli


### **Installation Steps**

1. Clone the repository:

git clone https://github.com/Siddh021/recipe-finder.git
cd recipe-finder


2. Install dependencies:

npm install


3. Start the development server:

ng serve


4. Open in browser:

http://localhost:4200/


The app reloads automatically when source files change.
